04 · Buttons

28 px, at most one primary per region. Danger is an outline, not a fill. Disabled is aria-disabled and loses the fill — never the native attribute, which would take the control out of the tab order and its explanation with it.

05 · Text input

The ring is the only focus signal; the border does not change colour. Invalid is a danger border and a message — never the border alone.

06 · Banner

Label, then cause, then what would change it. Status colour is text and a 2 px left border — never a filled block, because a filled red panel in a 320 px strip reads as a crash. Never stacked more than one deep; a second condition replaces the first.
